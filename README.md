# Траектория · платформа подготовки

Локальная версия на основе «Хроники». Семь направлений, общий профиль, теория, практика, ошибки, интервальное повторение и план на день. Реализован работающий учебный цикл; полнота курсов и соответствие экзаменационным спецификациям пока не заявляются.

## Запуск

Нужен Node.js 22 или новее. Установка пакетов и сборка не требуются.

В Windows можно открыть `start-local.cmd`. Либо выполнить в папке проекта:

```powershell
node scripts/serve.mjs
```

Откройте `http://127.0.0.1:4173`. Сервер слушает только локальный компьютер. Для остановки нажмите Ctrl+C в его окне. Открытие `index.html` двойным щелчком не заменяет сервер: учебные материалы загружаются из JSON.

Если npm есть, доступны `npm start`, `npm test`, `npm run validate`. Он не обязателен:

```powershell
node --test tests/core.test.mjs
node scripts/validate.mjs
```

## Как посмотреть результат

1. Откройте «Обществознание» → «Изучить». Прочитайте экономику и перейдите к практике.
2. Решите задания, укажите уверенность. Попробуйте ошибиться, правильно угадать, заполнить соответствие и написать план.
3. Выйдите из занятия и вернитесь: ответы и черновик сохранятся. Разбор контрольной тренировки появляется в конце.
4. Откройте ошибки, статистику и план. Повторение по сроку появится на следующий календарный день; ошибки можно отрабатывать сразу, но немедленное исправление не даёт закрепления.
5. В настройках создайте другого ученика и проверьте, что его прогресс отдельный. Выберите предметы, время, цель, дату и часовой пояс.
6. Экспортируйте профиль. При импорте появится предупреждение о замене; до неё сохраняется `trajectory_before_import_v1`.

## Данные и перенос

Исходные страницы: `legacy/index.html` и `legacy/map.html`. Они сохранены для сравнения и восстановления; не используйте старую и новую версии параллельно как синхронизированные тренажёры.

При открытии обновления **на прежнем origin** миграция автоматически копирует старые данные, сохраняя исходные ключи. Изолированные ученики остаются раздельными. Старые ответы, карта, ручной календарь, фильтры и план находятся в `profile.legacy`; сведения без известного владельца вынесены в отдельный архивный профиль. Старые ответы учитываются в охвате заданий, но не превращаются в новые датированные попытки или экзаменационные баллы.

Локальный просмотр на новом адресе не видит localStorage старого сайта. Можно импортировать прежний экспорт `history-ege-200` (только ответы). Для полной копии пользователь может выполнить код `scripts/legacy-backup.js` в консоли **своего старого сайта**, скачать JSON и импортировать его в настройки новой версии. Скрипт ничего не отправляет и не удаляет.

Полный экспорт всех профилей содержит чувствительные для ученика данные об обучении: сохраняйте файл у себя. Серверной регистрации и синхронизации нет.

## Материалы

- История: 200 исходных вопросов и 240 задач по 120 событиям карты; 56 конспектов о правителях; единая карта из 8 эпох.
- Обществознание: экономика, 10 заданий.
- Базовая математика: проценты, 5 заданий.
- Профильная математика: квадратные уравнения, 5 заданий.
- Русский: чередующиеся корни, 6 заданий.
- Информатика: алгоритмы и переменные, 6 заданий, трассировка, код без запуска.
- Физика: равномерное движение, 6 заданий, единицы, погрешность, график.

Новые материалы — авторские черновики, ожидающие независимой редакторской проверки. Все задачи проходят структурную проверку и проверку эталонного ответа. Это не заменяет содержательную экспертизу.

Название платформы меняется в `src/catalog.js` → `SETTINGS.platformName`. Для добавления материала используйте `data/modules.json`, затем запустите валидатор. Исторический источник извлекается командой `node scripts/extract-legacy.mjs`; стартовые материалы воспроизводит `node scripts/create-content.mjs`.

Документы: [аудит](docs/AUDIT.md), [архитектура](docs/ARCHITECTURE.md), [дорожная карта](docs/ROADMAP.md), [текущее состояние и продолжение](docs/STATUS.md), [проверки](docs/VERIFICATION.md).

Изменения находятся в ветке `feat/unified-learning-platform`. Сайт не опубликован, изменения не слиты в основную ветку.
