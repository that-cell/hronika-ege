## Что найдено
- Две самостоятельные страницы без системы сборки и внешних JS-зависимостей.
- Главная: 200 авторских вопросов со стабильными ID; 56 записей о правителях; 8 навигационных эпох. Основной тренажёр делит банк лишь на `early`/`late`.
- Карта: 6 эпох; 120 событий; генератор двух вопросов на событие (240 вариантов заданий). Дополнительные короткие вопросы и конспекты находятся в `eras` и `EXTRA`.
- Главная: эпохи 862–1054, 1054–1340, 1340–1533, 1533–1682, 1682–1825, 1825–1917, 1917–1991 и после 1991.
- Карта: 862–1237, XII–XV века, 1462–1613, 1721–1917, 1922–1991, после 1991. Периоды пересекаются; 1613–1721 и 1917–1922 явно не представлены отдельной эпохой.
- Фильтр главной строится по именам правителей. Часть вопросов имеет темы «Калка», «Причины и следствия» и не находит правителя. Финальная эпоха ограничена Дмитрием Медведевым, хотя годы Путина также есть в данных.
- На главной одна последняя запись ответа, счётчик попыток и флаг ошибки. Исправление сразу удаляет ошибку. Карта ставит «освоено» после полностью верной случайной подборки, без разнесения по дням.
- Генератор карты отбрасывает только одинаковый текст события, но не другие события того же года: возможно несколько фактически верных вариантов при единственном заявленном ответе.
- Календарь отмечается вручную. План фиксирован (35–50 минут), не зависит от ошибок и предметов.
- Экспорт `history-ege-200` версии 1 включает только `state`, без карты, профилей, календаря и плана.
- Первый вход вызывает блокирующий prompt для имени. В нескольких местах ошибки сохранения подавляются.

## Ключи localStorage
| Ключ | Содержимое / владелец |
| --- | --- |
| `chronika_profiles_v1` | Массив `{id,name}` |
| `chronika_active_profile_v1` | ID выбранного ученика, строка |
| `chronika_profile_legacy_claimed` | Маркер старого однократного присвоения данных |
| `history_ege_200_v1__<profile>` | Ответы, ошибки, попытки, фильтры и порядок |
| `chronika_daily_v1__<profile>` | Ручные дни, шаги плана, эпоха, открытый раздел |
| `hronika_map_v4_mastery__<profile>` | Флаги эпох по индексам карты |
| Те же три ключа без суффикса | Старый формат без владельца |
| Те же ключи с `__default` | Неименованный ученик |
| `history_ege_rurik_kalita_v1` | Более ранние ответы, отдельная индексация и порядок вариантов |
| `hronika_map_proto_v2` | Ранний прототип карты |

Неизвестные ключи с историческими префиксами также попадают в неизменяемый архив. Нельзя честно восстановить время, уверенность и каждую попытку из одного последнего ответа.

## План переноса
1. Снимок всех исходных ключей до записи нового хранилища; оригиналы остаются на месте.
2. Отдельный профиль для каждого известного ученика; данные без владельца — в отдельном архивном профиле, без автоматического присвоения.
3. Сохранение старых ответов, плана, календаря, карты и фильтров внутри `profile.legacy` с исходными значениями.
4. Новая статистика попыток начинается с известных датированных действий; старые ответы показываются отдельно и учитываются как уже встречавшиеся задания.
5. Карту и основной банк объединить вокруг одного каталога. Назначение тем по датам объяснений — первоначальная эвристика; нужна редакторская проверка пограничных и сквозных вопросов.
6. Проверить повторный запуск миграции, раздельных учеников, повреждённые данные, нехватку места, резервное копирование и перенос на другой origin.

## Что не утверждается
Авторский банк не равен полноценному варианту ЕГЭ. Материалы не сверены со всеми актуальными кодификаторами. Ни доля решённых заданий, ни старая отметка карты не дают достоверного прогноза баллов.
