# Дорожная карта

Сроки не назначены: сначала оцениваются качество банка и объём редакторской работы.

| Этап | Зависимости | Критерий готовности | Проверка |
| --- | --- | --- | --- |
| 1. Аудит и проектирование | Исходный checkout | Снимок, ключи хранения, расхождения, модель и решение по стеку | Сверка извлечённых данных с исходными страницами |
| 2. Общее ядро | 1 | Семь направлений, общая оболочка, профили, миграция, общий ввод и проверка | Unit-тесты типов ответов, профилей и миграции; сценарии в браузере |
| 3. Перенос истории | 2 | Сохранены материалы; общие темы для карты, практики и статистики; полный архив | Сверка всех 200 ID, 56 конспектов и 120 событий; проверка дистракторов и редакторская разметка |
| 4. Персональное обучение | 2, 3 | Попытки, уверенность, интервалы, ошибки, освоение, план по времени | Дни, часовые пояса, повторные решения, ошибки и импорт |
| 5. Обществознание | 2, 4 | Экономика: теория, разные задания, объяснения, повторение, статистика | Сценарий урок → практика → ошибки → повторение; независимая редакторская проверка; сверка структуры с ФИПИ |
| 6. Другие направления | 2, 4 | По одному замкнутому стартовому модулю в пяти направлениях | Материалы и ответы проверены; отдельные прогрессы; мобильный сценарий |
| 7. Экзаменационный режим | 3, 5, 6; официальные спецификации выбранного года; достаточный банк | Структура, таймер, сохранение, критерии, корректные первичные баллы | Эталонные варианты и сверка ФИПИ. До этого — только тематическая практика |
| 8. Дальнейшее развитие | Стабильное ядро | Серверная синхронизация, права преподавателя, редактор; расширение банка | Контракты синхронизации, безопасность и восстановление; экспертная оценка качества |

## Следующие завершённые изменения
1. Редакторская разметка всех исторических вопросов и проверка границ эпох; замена слабых дистракторов. Добавить источники, культуру и настоящие исторические карты с правами на изображения.
2. Независимая проверка стартовых модулей. Добавить экономический график, конструктор плана, текстовые фрагменты и больше разнообразных заданий; сверить тематическую сетку обществознания с кодификатором выбранного года.
3. Полные UI regression-тесты всех типов ввода, контрольного режима, повреждённых импортов и мобильной доступности.
4. Механизм конкурентного сохранения для нескольких вкладок, IndexedDB при росте истории, восстановление из резервной копии через интерфейс.
5. Только после контентной подготовки приступать к полноценным пробникам.
