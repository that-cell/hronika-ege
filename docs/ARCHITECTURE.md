# Архитектура платформы

## Решение по стеку
Статический HTML, CSS и ES-модули. Сервер и фреймворк пока не нужны: исходный проект работает без сборки, учебный цикл и сохранение выполняются в браузере. Node.js нужен только для локального сервера, извлечения материалов и тестов. Зависимостей из npm нет.

## Границы
- `src/app.js`: общие экраны, управление учебной сессией, доступный ввод.
- `src/catalog.js`, `data/*.json`: предметы, темы, уроки и версионированные задания.
- `src/engine.js`: проверка ответов без зависимости от DOM.
- `src/learning.js`: попытки, интервалы, статистика, освоение и план.
- `src/storage.js`: адаптер localStorage, миграция, резервные копии и импорт.
- `legacy/`: точные исходные страницы. Они сохраняют старые правила и не являются новым интерфейсом.

## Сущности
Store(schemaVersion, activeProfileId, profiles, migration). Profile(id, name, settings, attempts, reviews, lessons, session, legacy). Settings(selectedSubjects, minutes, goals, examDates, timezone). Subject(id, title, accent, topics). Topic(id, subjectId, title, lesson, questionIds). Question(id, version, subjectId, topicIds, type, prompt, answer/rubric, explanation, difficulty, source, reviewStatus). Attempt(id, questionId, questionVersion, subjectId, topicIds, at, localDate, answer, correct, elapsedMs, mode, confidence, selfAssessed). Review(questionId, stage, due, lastSuccessDay, spacedSuccesses, unresolvedError). Session(ids, index, mode, responses, startedAt). ExamSpec(year, source, verificationStatus, structure, criteriaVersion).

ID стабильны, математические направления независимы. Попытки хранятся неизменно; производные показатели вычисляются из них. Старые ответы не превращаются в датированные попытки, а старые отметки карты — в новое «закреплено». Данные без известного владельца хранятся отдельно.

## Правила обучения
Повторение через 1, 3, 7, 14, 30 календарных дней. Ошибка или сомнение возвращают к первому интервалу. Повторный успех в тот же день не продвигает интервал. Устойчивое исправление ошибки: два уверенных успеха в разные дни. Закрепление темы: не менее 3 разных заданий, 2 разных учебных дней, точность не ниже 80%, нет неотработанных ошибок и просроченных повторений. Правильное угадывание требует повторения.

Учебная активность — отправленная попытка или явно завершённый урок. Ручных огоньков в новой статистике нет. День рассчитывается по IANA timezone профиля. Экзаменационный прогноз не выводится.

## Расширение
Новый материал добавляется в JSON; `npm run validate` проверяет схему, ID, ссылки и ответы. Новый тип задания добавляется в валидатор, проверяющий модуль и общий компонент ввода. Для серверной синхронизации можно заменить адаптер хранилища; локальные профили не представляются защищёнными аккаунтами.

## Миграция и перенос на другой адрес
localStorage доступен только в том же origin. При размещении обновления на старом адресе миграция запускается автоматически. Для перехода с другого адреса нужен экспорт старого тренажёра; он переносит только ответы. Для полной копии исходных ключей предусмотрен `scripts/legacy-backup.js`, запускаемый пользователем на старом сайте. Новый импорт распознаёт оба формата. Исходные ключи никогда не удаляются.
