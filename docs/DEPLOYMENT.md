# Публикация через GitHub и Netlify

Репозиторий: https://github.com/that-cell/hronika-ege

Рабочая ветка платформы: `feat/unified-learning-platform`. Отправлена в GitHub. Основная ветка не изменена.

## Конфигурация

В `netlify.toml` заданы Node.js 22 и каталог публикации `dist`. Перед сборкой выполняются 35 тестов и валидация материалов. Команда сборки копирует только файлы сайта, исходные учебные данные и браузерные модули; локальные сохранения, инструменты разработки и Git-архив в публикацию не попадают.

Для непрерывных обновлений Netlify должен быть связан с этим репозиторием и веткой. Наличие `netlify.toml` само по себе не создаёт эту связь. Состояние подключения и адрес сайта будут записаны после подтверждённой публикации.

Netlify CLI установлен отдельно в рабочие инструменты этой сессии, а не в зависимости платформы. Авторизация проходит через официальный браузерный запрос; ключи не добавляются в репозиторий.

## Обновления

После подключения Git изменения отправляются в выбранную ветку. Netlify получает обновление, запускает тесты, собирает статические файлы и публикует успешную версию. Изменение домена не переносит localStorage: пользователю нужно экспортировать и импортировать свой профиль. Обновление на том же адресе сохраняет локальные данные браузера.
